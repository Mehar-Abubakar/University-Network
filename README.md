# University Network — Cisco Packet Tracer

A simulated secure campus network built in Cisco Packet Tracer, designed for a multi-building university setup with routing, VLANs, and WAN connectivity between departments.

## Overview

This project simulates a network architecture for a university spread across multiple buildings (East and West), each with its own set of departments. It demonstrates how routing protocols, DHCP, and WAN technologies work together to connect a large, distributed campus to a central data center and the internet.

## Objectives

- Understand how to establish a network for an organization end-to-end.
- Simulate a realistic campus network using Cisco Packet Tracer.
- Get hands-on experience with core networking protocols (routing, DHCP, WAN switching).

## Key Features

- **Multi-building topology** — East and West buildings, each hosting several departments.
- **DHCP servers** in both East and West buildings for dynamic IP address assignment to hosts.
- **EIGRP routing**, along with static and default routing, used across different branches.
- **Frame Relay switching** for WAN connectivity between the buildings, the data center, and the internet via an ISP.
- **Protocol redistribution** enabling departments running different routing protocols to communicate with each other.
